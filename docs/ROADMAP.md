# Roadmap

Статусы: 💡 идея · 🔨 в работе (ветка) · 🧪 ждёт проверки · ⚠️ работает частично · ✅ готово

## Модули

| Модуль | Что настраивает | Статус |
|---|---|---|
| Строка меню | Отступы значков (`NSStatusItemSpacing`, `NSStatusItemSelectionPadding`) | ⚠️ на macOS 27.2 работает только для сторонних значков: ControlCenter (батарея, Wi‑Fi, Bluetooth, язык) ключи не учитывает |
| Dock | Пробелы между значками (`spacer-tile`, `small-spacer-tile`), резервная копия и восстановление | ✅ проверено на macOS 27.2 |
| Finder | Скрытые файлы, расширения, путь и статус-бар, вид по умолчанию, поиск в текущей папке, без `.DS_Store` на сети/USB | 💡 |
| Скриншоты | Папка, формат (png/jpg), без тени окна, без плавающей миниатюры | 💡 |
| Клавиатура | Скорость повтора и задержка, повтор вместо меню акцентов, отключение автозамены и «умных» кавычек | 💡 |
| Трекпад и мышь | Тап для клика, перетаскивание тремя пальцами, скорость | 💡 |
| Строка меню Mac Tweaks и «Не засыпать» | Значок-ключ в строке меню, режим «не засыпать» на 15 мин–8 ч или без срока (IOPMAssertion), «не гасить экран»; раздел «Приложение»: значок в строке меню/Dock, запуск при входе | 🧪 сделано (`feature/menubar-awake`), ждёт проверки пользователем |
| Окна и анимации | Ускорение/отключение анимаций, двойной клик по заголовку | 💡 |

## Идеи для модуля Dock

| Функция | Ключи `com.apple.dock` | Статус |
|---|---|---|
| Автоскрытие без задержки и быстрая анимация | `autohide-delay`, `autohide-time-modifier` | 💡 |
| Убрать «недавние приложения» | `show-recents` | 💡 |
| Показывать только запущенные приложения | `static-only` | 💡 |
| Полупрозрачные значки скрытых приложений | `showhidden` | 💡 |
| Сворачивать окна в значок приложения | `minimize-to-application` | 💡 |
| Эффект сворачивания scale/genie | `mineffect` | 💡 |
| Прокрутка по значку показывает окна | `scroll-to-open` | 💡 |
| Заблокировать размер, положение и содержимое | `size-immutable`, `position-immutable`, `contents-immutable` | 💡 |
| Сброс Dock к заводскому виду | удаление домена + `killall Dock` | 💡 |
| Пробелы в правой части Dock | `persistent-others`, работает на macOS 27.2 | ✅ |
