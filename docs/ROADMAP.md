# Roadmap

Статусы: 💡 идея · 🔨 в работе (ветка) · 🧪 ждёт проверки · ✅ готово

## Модули

| Модуль | Что настраивает | Статус |
|---|---|---|
| Строка меню | Отступы значков (`NSStatusItemSpacing`, `NSStatusItemSelectionPadding`) | 🧪 сделано, ждёт проверки на macOS 27 |
| Dock | Автоскрытие, задержка и скорость появления, размер, «недавние» приложения, только открытые приложения | 💡 |
| Finder | Скрытые файлы, расширения, путь и статус-бар, вид по умолчанию, поиск в текущей папке, без `.DS_Store` на сети/USB | 💡 |
| Скриншоты | Папка, формат (png/jpg), без тени окна, без плавающей миниатюры | 💡 |
| Клавиатура | Скорость повтора и задержка, повтор вместо меню акцентов, отключение автозамены и «умных» кавычек | 💡 |
| Трекпад и мышь | Тап для клика, перетаскивание тремя пальцами, скорость | 💡 |
| Окна и анимации | Ускорение/отключение анимаций, двойной клик по заголовку | 💡 |

## Общие функции приложения

| Функция | Зачем | Статус |
|---|---|---|
| Профиль: экспорт/импорт всех настроек в файл | Перенести свою конфигурацию на новый Mac в один клик | 💡 |
| «Применить всё из профиля» | Быстрая настройка чужого Mac | 💡 |
| Иконка приложения | Сейчас стандартная | 💡 |
